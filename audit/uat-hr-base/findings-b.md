## Temuan/Anomali
1. **[Minor][Template Surat] Teks ringkasan header tidak konsisten dengan katalog** — Header menulis "28 template … 3 disipliner · 12 personnel action · 5 surat layanan karyawan · 4 rekrutmen" (jumlah 24), padahal total 28 karena kategori **KINERJA (4 template: PERF_PIP, PERF_RESULT, dll.) tidak disebut** di ringkasan. Kartu aktual = 28 (benar).
2. **[Minor][Template Surat] Flash state "0 template"** — ±2–3 detik pertama halaman menampilkan "0 template surat siap cetak" sebelum data termuat (async); berpotensi membingungkan sesaat.
3. **[Minor][Laporan HR — Demografi] Inkonsistensi grafik gender** — Pie "Komposisi Gender" menampilkan Laki-laki 25 · Perempuan 17 · slice ketiga berlabel "P" 1, sedangkan crosstab "Gender × Status Kepegawaian" menghitung Laki-laki 26 · Perempuan 17 (total sama 43). Ada 1 karyawan yang di pie dianggap kategori terpisah "P" tapi di crosstab digabung ke Laki-laki → definisi/normalisasi nilai gender tidak konsisten antar widget.
4. **[Bug responsif][Direktori Karyawan mobile] Horizontal overflow 98px (390px viewport)** — Baris aksi atas (Onboarding/Import Excel/Export Excel) tidak membungkus (Export Excel off-screen) dan chip filter "Kontrak 6"/"Non-aktif 2" keluar viewport (hingga x=557). Perlu wrap pada action row dan scroll-x bersyarat atau wrap pada chips.
5. **[Transient][Infra] Dev server restart di tengah sesi** — Saat membuka Direktori mobile muncul "Gagal memuat direktori — Failed to fetch"; `curl localhost:3000` konfirmasi server down (exit 7). Setelah tunggu 30 detik (watchdog auto-restart) + reload, data termuat normal. Bukan bug aplikasi, hanya dicatat; console Fast Refresh rebuilding mendukung kesimpulan ini.
6. **[Minor][PWA] Prompt instal muncul lagi di mobile** meski flag `rekankerja:pwa-dismissed=1` sudah dipasang di awal sesi — prompt bisa ditutup via "Nanti" (tidak menghalangi), tapi cek dismissal mungkin tidak memperhitungkan kondisi viewport mobile.
7. **[Info][Pengumuman] Progres dibaca rendah** — 2 pengumuman terbit hanya dibaca 4/43 (9%) — data seed, bukan bug; hanya konteks.

## Kesimpulan
Seksi DOKUMEN & SURAT, KOMUNIKASI, dan LAPORAN berfungsi baik dengan data nyata (28 template, 3 pengumuman, 16 laporan standar + builder kustom 6 entity). Mobile dashboard solid (bottom nav + drawer, tanpa overflow). Satu-satunya kegagalan adalah **overflow horizontal minor di Direktori Karyawan mobile** (action bar + chip filter). Footer sehat di semua halaman (static, bukan overlay). Tidak ada error JS di console.
