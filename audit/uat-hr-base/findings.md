## Temuan/Anomali

1. **(Minor, UX) Tombol "Kembali ke Daftar" pada detail pengajuan selalu kembali ke "Semua Pengajuan"** — masuk dari menu "Menunggu Persetujuan" → klik detail → "Kembali ke Daftar" mendarat di `actions/all` (Semua Pengajuan), bukan kembali ke inbox "Menunggu Persetujuan". Kode: `actions-module.tsx` line ~629 `navigate("actions","all")` tanpa mengingat asal. Tidak fatal, tapi alur balik kurang intuitif bagi approver.
2. **(Data) Inkonsistensi tanggal pada PA-2026-0002** — "Dibuat: 9 Agu 2026" tapi "Submit: 17 Apr 2026" (submit mendahului created ~4 bulan); jejak aktivitas tertulis "Submitted 26 Okt 2026". Tanggal efektif 18 Jul 2026 juga mendahului tanggal submit. Ini anomali data seed, bukan bug render.
3. **(Data) Seed kosong untuk Dokumen Karyawan** — API mengembalikan 0 dokumen; fitur monitor kedaluwarsa 30/60/90 hari tidak bisa di-UAT dengan data nyata. Disarankan menambah seed (mis. KTP/paspor dengan tanggal kedaluwarsa bervariasi) agar filter ≤30/≤60/≤90 hari dapat diverifikasi.
4. **(Data) Tanggal penugasan aset seragam "28 Jun 2026"** — 4 assignment aktif semuanya bertanggal 28 Jun 2026 (masa depan relatif terhadap data lain yang ber-2025); jejak waktu seed tidak bervariasi. Kosmetik.
5. **(UX, perlu konfirmasi desain) Command palette tidak memfilter daftar menu** — ketika mengetik "Dedi", section "Navigasi" tetap menampilkan SEMUA menu tanpa filter; hanya section "Karyawan" yang terfilter. Jika maksudnya menu bisa dicari juga, filter menu tidak bekerja; jika memang desain (menu selalu tampil), abaikan.
6. **Radix Tabs perlu event mousedown** (info QA, bukan bug produk): klik programatik `.click()` pada tab "Penugasan" tidak mengganti tab; perlu dispatch mousedown+mouseup+click. Klik manual oleh user asli tidak terdampak.
7. **Console bersih** — tidak ada error/warning JS selama seluruh sesi (hanya log Fast Refresh dev server). Tidak ada skeleton macet; semua fetch selesai.
8. **Statistik dashboard konsisten** — badge "Menunggu Persetujuan 2" di sidebar cocok dengan isi inbox (2 PA) dan widget dashboard.
